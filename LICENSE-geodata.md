# Geographic reference data attribution

Country and administrative subdivision labels in `geo-countries.js` and `geo-states.js` are adapted from **Countries States Cities Database** by Darshan Gada and contributors:
https://github.com/dr5hn/countries-states-cities-database

The source data is available under the Open Database License (ODbL 1.0):
https://opendatacommons.org/licenses/odbl/1-0/

Changes: selected fields were normalized into compact JavaScript arrays, ISO-2 country codes were grouped into six MESHTEC mockup geographic regions, and administrative areas were limited to the first-level entries where `parent_id` is null.

This is a geographic reference dataset, not evidence that MESHTEC manufactures, distributes, or provides products in every country or state. The prior network references are marked separately in the mockup.
